Introducing Romans‑19e

Our second model, and 113 times bigger than the first. 91 million parameters trained from scratch on 1,029 French novels of the nineteenth century. It writes like Dumas on a deadline: impeccable dialogue dashes, period spelling, and a plot that forgets itself every few sentences.

The model

We rented a GPU. We are not proud of it.

HomamadeLLM was founded on a simple principle: no GPUs. Then we did the maths. A 91-million-parameter model on our 2015 laptop would have taken around ten days of training. So for 165 minutes, and for the first time in our history, we borrowed one NVIDIA L4 in a Google Cloud data centre in Zurich. The virtual machine was deleted the moment the weights came home.

Romans-19e is a decoder-only transformer that continues French prose. Give it the first words of a sentence and it writes what a nineteenth-century novelist might have written next: dialogue, description, sometimes a chapter title or a publisher's notice. It learned all of this, spelling included, from raw text and nothing else.

i.

Still runs on a CPU

Training needed a GPU; using the model does not. A few hundred words take a few dozen seconds on an old laptop.

ii.

Open all the way down

Public-domain texts, a CC0 dataset, MIT-licensed weights and code. Every step from Gutenberg to the Hub is published.

iii.

Its own tokenizer

An 8,192-token byte-level BPE trained on the corpus itself, so accents and French words cost fewer tokens than with GPT-2's.

The dataset

A library of 1,029 French books, free for anyone

The model is only as good as what it reads, so we built the corpus ourselves and publish it alongside the model. Every book comes from Project Gutenberg, is written in French, and is by an author who died in 1955 or earlier, which puts it in the public domain in France as well as in the United States.

Evaluation

From random bytes to almost-Balzac

Training starts at a loss of 9.15, roughly what you get by guessing uniformly among 8,192 tokens. After 7,000 steps it reaches 2.90 on eighteen books the model never saw. The gap with the training loss (2.61) widens slowly towards the end: after four passes over the corpus, the model starts to memorise some of what it has read.

Quickstart

Run it in three steps

You need Python 3.9 or newer. No GPU, no account, no API key. The weights (367 MB) are published at huggingface.co/phuvey/romans-francais-19e-gpt.

  1. Install the dependencies

    PyTorch runs the model, safetensors reads the weights, tokenizers turns text into tokens, and huggingface_hub provides the hf download command.

    pip install torch safetensors tokenizers huggingface_hub

  2. Download the model

    This fetches the weights, the config, the tokenizer, the model definition and a ready-made generate.py. You can also download the files by hand.

    hf download phuvey/romans-francais-19e-gpt --local-dir romans-francais-19e-gpt
cd romans-francais-19e-gpt

  3. Generate text

    Give it the opening of a sentence, in French.

    python generate.py "Il pleuvait sur Paris" --max_new_tokens 300 --temperature 0.8 --top_k 200

    Things to try: lower --temperature to 0.5 for safer, more repetitive prose, raise it to 1.0 for surprises. --num_samples 3 writes three continuations of the same prompt, --seed makes a run reproducible. Dialogue works well: start with a dash, as in "—Monsieur, dit-elle,".

How we built it

Six steps, one laptop, one rented GPU

The full pipeline, from the Gutenberg catalogue to a published model. Training uses nanoGPT by Andrej Karpathy, unmodified; everything else is a short Python script, one per step.

  1. Select the books

    From the Project Gutenberg catalogue we keep French fiction (novels, tales, short stories) by authors born between 1770 and 1870 who died in 1955 at the latest. Gutenberg only guarantees US copyright; this cut-off makes the texts public domain in France too.

  2. Clean and deduplicate

    We strip Gutenberg headers, digitisation credits, transcriber notes and tables of contents, rejoin broken lines and normalise typography. Gutenberg often hosts the same story twice, once alone and once inside "Complete Works", so a book is dropped when half of its 8-word sequences already appear in a longer one: 41 books went. Books are then split between training and validation by a hash of their Gutenberg id, so no book ends up on both sides.

  3. Train a tokenizer

    A byte-level BPE with 8,192 tokens, learned on the training books. It averages 3.6 characters per token on this corpus, against 2.7 for GPT-2's tokenizer: the model sees more text in the same context window.

  4. Choose the architecture

    The shape of GPT-2 small, with a vocabulary built for French.

    Layers12
    Attention heads12
    Embedding size768
    Context length512 tokens (~1,800 characters)
    Vocabulary8,192 BPE tokens
    Parameters91.2 M

  5. Train on a GPU, for once

    Each step reads 128 excerpts of 512 tokens (65,536 tokens) and nudges all the weights with AdamW. 7,200 steps, about 1.3 seconds each, on a single NVIDIA L4: 2 hours 45 minutes in total. A checkpoint is kept only when the validation loss improves; the best one came at step 7,000. 

    python train.py config/train_romans19.py

    Hardware: Google Cloud g2-standard-4, 1 × NVIDIA L4, bfloat16, torch.compile.

  6. Export and publish

    The checkpoint is a Python pickle that also holds the optimizer state. We keep only the weights, save them as safetensors (plain data, no code), and upload them with the config, the tokenizer, the model code and a generation script. The corpus goes on the Hub too. 

    hf upload phuvey/romans-francais-19e-gpt hf-romans19 .
hf upload phuvey/romans-francais-19e corpus/dataset . --repo-type dataset

Responsible release

What it cannot do

We believe in being direct about limitations. There are fewer than last time, but not many fewer.

  • It loses the plot. Grammar is mostly right, but characters change names, appointments move from three o'clock to midnight, and a man holds his rifle "on his head".
  • It is not a chatbot. It continues text. It does not answer questions, follow instructions, or know facts; anything that looks like a fact is invented.
  • It may quote its sources. Having read the corpus four times, it can reproduce passages from the books. They are public domain, but check before calling an output original.
  • It thinks it is 1850. The books carry the colonial, racist, antisemitic, sexist and class prejudices of their time, and the model reproduces them.
  • It sometimes writes the paratext. Prefaces, footnotes, chapter titles and old publishers' notices were left in the corpus, and the model produces them too.
